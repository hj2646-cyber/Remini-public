## 1. 데이터셋 명세 (가이드라인 v0.4, 2020-12-07)

- **이름**: 자유대화 음성 (노인남여) — 데이터2 (AI Hub `dataSetSn=107`)
- **타겟 화자**: 60세 이상 남녀 (1:1 비율)
- **규모**: **1,000명 이상 화자 / 3,000 시간 이상 음성**

## 7. 재현 절차

1. AI Hub 107 가입 + 승인 (1~3일)
2. AIHubShell 부분 다운: `aihubshell -mode d -datasetkey 107 -filekey 48665,48666,48675,48676,48679,48680,48683,48684 -aihubapikey <KEY>` (Plan A, 52GB) + `-filekey 48664,48669` (Plan B, 30GB)
3. 모든 부분 zip 수동 unzip (aihubshell auto-unzip 은 download.tar 만 풂)
4. `finetune/scripts/30_aihub107_explore.py` → utterances.jsonl + _stats.json 재생성
5. `31_aihub107_prepare.py` → HF Arrow dataset (train/eval) 재생성
6. `32_qwen3_asr_lora.py` 학습 (5h, H200) → adapter
7. `33_qwen3_asr_eval.py` → results.json
8. `34_merge_lora.py` → merged model
