- 생성일: 2026-05-28
- 환자 페르소나: **P001 김영자** (1948-03-14, 78세) · 전북 전주 서노송동 출신 · 초등학교 교사 30년. 어머니 **박복례**(가장 그리워함), 남편 **이정호**, 첫딸 **이은정**, 무릎 관절염·혈압약, 이미자·뜨개질·전원일기 선호. (출처: ai-server Neo4j KG)
- 시스템 구성:
  - **Remini(우리)**: ai-server 파이프라인 — Neo4j P001 KG(EchoRoute retrieval) + bge-m3 임베딩 + DSLM `remini-stage25-book`(Ollama)
  - **Gemini**: `gemini-2.5-flash` — **동일 입력**(같은 retrieval 컨텍스트 + 같은 SYSTEM_PROMPT)에 LLM만 교체한 공정 비교
- 평가 항목: 14문항(음성 Q4 제외) — 발화별 매핑은 표의 '항목' 열
- ⚠️ **검토용**(모델명 노출). 전문가 블라인드 배포 시 '시스템 A/B' 익명화 + 좌우 순서 카운터밸런싱 별도 적용
