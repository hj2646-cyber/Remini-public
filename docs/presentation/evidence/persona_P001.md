## 10. 회상요법 적용 시 핵심 트리거 (전문가 검증 포인트)

### A. 강한 정서 기억 (편도체 보존, 가장 안전한 회상 화제)

1. **남편 이정호** — WAS_CLOSE_TO + 작은 수첩 (남편이 써 줌) → 사별 추정 시 NVC 7장 「슬픔 맛보기」 적용 필수
2. **어머니 박복례** — 가장 보고 싶은 사람 (MISSES) → 그리움 정서, 1H 화법
3. **고향 전주 서노송동 한옥집·골목** — 시각·청각 회상 단서 풍부

### B. 안전한 즐거운 회상 (긍정 정서)

1. **결혼 (금테 안경)** + **신혼**
2. **1988년 경주 불국사** 여행
3. **1989년 추석 가족 한복 사진** — 명절·가족
4. **고등학교 친구 최말순** + **친구들이랑 모이던 시절**
5. **남부시장 칼국수집** 가족 외식
6. **고무줄놀이·공기놀이** (10-15세 ADL 기억 활성화)
7. **하모니카·뜨개질·화분 가꾸기** (절차 기억)
8. **이미자 노래·전원일기** (청각 단서)
9. **콩나물국밥·김치전** (미각·후각 단서)
10. **초등학교 교사 시절** + 동료 박선생 + 학생들 + 손글씨

### C. 주의 화제 (Validation Therapy 적용 — 사실 검증 X)

1. 남편이 살아계신 것처럼 말할 때 → 교정 X, 따라가기
2. "오늘 학교 가야 한다" 같은 시점 혼동 → 교정 X
3. 무릎 통증 호소 → closed 질문 + 가족 권유 (진단·약 안내 X)

### D. 추천 회상 화제 우선순위 (회상요법 룰 + 본 페르소나)

1. **봄**: 좋아하는 계절 + "다시 가보고 싶은 전주 한옥마을"
2. **음식**: 콩나물국밥 향 → 어머니·고향 → 가족
3. **노래**: 이미자 노래 → 청각 회상 → 그 시절 분위기
4. **사진 보여주기**: 1989년 추석 한복 사진 → 가족·명절·한복
5. **하모니카·뜨개질**: 절차 기억 활성화 → 감각·동작
6. **어린 시절 놀이터**: 개울가·운동장 → 친구·놀이
