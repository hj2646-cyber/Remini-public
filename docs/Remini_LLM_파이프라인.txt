채택 이유 (3줄)
 - 한국어 자연스러움 + 중·소형 모델에서도 instruction-following 우수
 - 완전 로컬 → 의료 데이터 외부 유출 zero
 - Ollama 친화적 → 모델 교체/실험 속도 ↑

4. 단계별 상세
--------------------------------------------------------------------------------

[① STT — Faster-Whisper]
 - 모델 : small / int8 양자화
 - 옵션 : language=ko, vad_filter=True, beam_size=5
 - 평균 latency : ~0.4s/문장 (H200 GPU)

[② Pre-Filter]
 - 키워드 사전(욕설/자해/약물 오남용) → 즉시 차단 응답
 - 빈 발화·환경 소음 → 응답 생략 후 Proactive 모드 대기

[③ Mode Router]
 routine_support  : "약/식사/잠" 등 daily hint  → 일상 보조
 memory_support   : "옛날/가족" 등 life hint    → 회상치료
 emotion_grounding: 감정 단어 / 저음·침묵       → 정서 안정화
 bridge_mode      : 모드 전환 buffer            → 자연스러운 화제 전환

[④ RAG (3-Tier)]
 1순위 Neo4j AuraDB — Cypher, 모드별 daily/life budget
 2순위 pgvector     — bge-m3 코사인 유사도 TOP-K
 3순위 JSON 폴백    — 토큰 교집합

[⑤ Prompt Builder 구조]
   [SYSTEM]  치매환자 대화 가이드 + 안전 규칙
   [PERSONA] 환자 이름·나이·성격·말투
   [CONTEXT] RAG evidence (KG 조각 + vector hits)
   [HISTORY] 최근 4턴 대화 + 장기 요약
   [USER]    현재 발화
   [STYLE]   따뜻함·짧은 문장·반복 허용

[⑥ Ollama 추론 파라미터]
   model        : qwen2.5:14b / qwen3:35b
   temperature  : 0.6
   top_p        : 0.9
   max_tokens   : 256
   stop         : ["[USER]", "\n\n\n"]

[⑦ Post-Filter (3-Stage Risk Management)]
 (1) Rule Filter    — 의료조언/진단/약물 변경 금지
 (2) Prompt Design  — System Prompt에 안전 규칙 명시
 (3) Caregiver Loop — 의심 응답 → 보호자 앱 피드백 카드

[⑧ TTS 진화]
 1단계 : TTSForge (실험)              → 음질 부족
 2단계 : Edge-TTS ko-KR-SunHiNeural   → 안정 운영
 3단계 : XTTS v2 가족 음성 클로닝     → 진행 중

[ⓐ~ⓔ 백그라운드]
 - 새 지식 감지 → 재확인 → 보호자 승인 → Neo4j 반영
 - 대화 요약 → 장기 메모리 압축
 - Face Mesh: 눈감김/침묵 임계 초과 → AI 선제 발화
