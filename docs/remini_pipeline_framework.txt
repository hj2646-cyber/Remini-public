[0] 시스템 한 줄 요약
--------------------------------------------------------------------------------

[3] 상태 머신 (shuo-style State Machine)
--------------------------------------------------------------------------------

         ┌──────────────┐   StartOfTurn   ┌──────────────┐
         │  LISTENING   │ ─────────────►  │  RESPONDING  │
         │              │                  │              │
         │  마이크 청취   │ ◄─────────────  │  LLM+TTS 출력  │
         └──────────────┘   TurnDone /     └──────┬───────┘
                ▲           CancelAgent           │
                │                                  │
                └────── Barge-in (StartOfTurn) ◄──┘
                        + ClearPlaybackBuffer

  Events  : StartOfTurn, EndOfTurn(text), TurnDone, Error
  Actions : StartAgent(text), CancelAgent, ClearPlaybackBuffer
  파일     : ai-server/app/conversation/state.py, loop.py, agent.py

[9] 핵심 설계 포인트 (발표 강조용)
--------------------------------------------------------------------------------
  1) 듀얼 채널: 환자(음성)와 보호자(데이터)를 분리하여 동시 운용
  2) 상태머신 기반 음성 루프: LISTENING ↔ RESPONDING + Barge-in 지원
  3) 스트리밍 LLM→TTS: 첫 음성까지의 지연(latency) 최소화
  4) GraphRAG 장기기억: 치매 환자 회상 대화에 특화
  5) 가족 목소리 복제 TTS: 정서적 친밀감 강화
  6) 보호자 승인형 지식 학습 루프: 잘못된 기억 주입 방지
  7) Proactive Agent: 약·안부·기념일 능동 대화
