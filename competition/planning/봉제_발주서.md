# 봉제 인형 외장 외주 발주서 — Remini 시연용

> 별첨: `competition/planning/인형_정면도.svg` (정면 도면, 브라우저에서 열어 확인)
> 예산: 150,000원 (목표 범위 150,000~180,000원, 디자인 복잡도 따라 조정 가능)
> 납기: **3~4주 안에 완성품 수령 필요**
> 수량: **샘플 1개** (캡스톤 시연용 단일 prototype)

## 1. 인형 사양 요약

| 항목 | 사양 |
|---|---|
| 형태 | **곰돌이형** (효돌 Hyodol 참고, 둥근 머리·둥근 몸) |
| 전체 높이 | **40cm** (앉은 자세 기준) |
| 머리 | 폭 24cm × 높이 20cm (둥근 사각형) |
| 몸 | 폭 22cm × 높이 18cm (타원형) |
| 귀 | 지름 6cm × 2개 (양쪽 머리 상단) |
| 팔 | 길이 12cm × 너비 6cm × 2개 |
| 다리 | 길이 10cm × 너비 7cm × 2개 |
| 색상 | **베이지/크림 (피부톤)** 권장. 변경 가능 |
| 패브릭 | 부드러운 단모 펠트 또는 미니키미모 (어르신 손에 닿기 좋은 촉감) |

## 2. 핵심 — 절개부 (디스플레이/카메라/스피커/마이크용 구멍)

⚠️ **이 부분이 일반 봉제 인형과 가장 다름**. 정확한 위치·크기 준수 필요.

| 위치 | 절개부 | 크기 | 형태 | 비고 |
|---|---|---|---|---|
| 머리 정면 중앙 | **디스플레이** | 16cm × 9cm | 직사각형 | 가장자리 내구성 마감 (오버록 또는 바이어스) |
| 머리 정면 하단 | **카메라** | 지름 2cm (원형) | 원형 | 디스플레이 아래 약 2cm |
| 머리 정면 입 위치 | **마이크 통풍구** | 지름 4mm × 5개 (점선 배치) | 작은 구멍 5개 | 카메라 아래 약 2cm |
| 몸 정면 중앙 | **스피커 그릴** | 지름 5cm (원형) | 원형 | 몸 중앙 |
| 등판 (전체) | **지퍼** | 25cm 길이 | 직선 | YKK 또는 동급, 등 중앙 세로 |

**절개부 위치 다이어그램:**
```
       ◯  ◯           ← 귀 (장식)
    ┌──────┐
    │ ▓▓▓▓ │           ← 디스플레이 (16×9cm)
    │ ●    │           ← 카메라 (φ2cm)
    │ ░░░░ │           ← 마이크 5개 구멍 (φ4mm)
    └──────┘
    /      \
   |  ●     |           ← 스피커 (φ5cm) - 몸 중앙
   |        |
   └─┐  ┌──┘
     │  │
```

→ 정면도 SVG 파일(`인형_정면도.svg`)을 봉제 업체에 함께 전달.

## 3. 측면/후면 사양

### 측면
- 머리 두께: **12cm 이상** (ABS 박스 24×20×**12cm** 가 들어가야 함)
- 몸 두께: 14cm
- 측면 절개 없음 (귀는 측면 봉제 시 부착)

### 후면 (등판)
- **세로 지퍼 25cm** (YKK 등급) 머리~몸 중앙
  - 목적: ABS 박스 안 부품(microSD/케이블) 접근 + 유지보수
- **환기구 (메쉬 패치)**: 등 상부 또는 어깨, 가로 5cm × 세로 3cm
  - 목적: Pi 5 + 액티브 쿨러 발열 외부 배출
- **USB-C 케이블 통과구**: 등 하단, 지름 1cm 원형
  - 목적: 외부 어댑터 연결 (시연 시 책상 위 어댑터)

## 4. 패브릭 자재

| 자재 | 사양 | 비고 |
|---|---|---|
| 외피 | 단모 펠트 또는 미니키미모 (단모 1~2mm) | 베이지/크림 |
| 안감 | 부드러운 면 또는 폴리 | 부품과 직접 접촉, 자극 없는 재질 |
| 솜 | 폴리 충전솜 | 외주 자재 포함 또는 별도 제공 |
| 메쉬 (환기) | 통풍 메쉬 | 등판 환기구용 |
| 지퍼 | YKK 25cm | 등판 |

→ 외주 업체가 자재 포함 견적 주면 OK, 아니면 자재 별도 제공.

## 5. 납기 / 일정

```
Day 1 (발주일) ─ 견적 요청 + 도면 전달
Day 3~5       ─ 견적 확정 + 계약금 입금 (보통 50%)
Day 5~7       ─ 1차 패턴 / 샘플 confirmation (사진/영상)
Day 7~21      ─ 실제 봉제 진행
Day 21~28     ─ 완성 + 검수 + 배송
Week 4 도착    ─ 부품 매립 시작
```

**critical**: 도면 전달 후 **계약금 입금 + 1차 confirmation 빠르게 처리**. 안 그러면 Week 5~6 도착으로 시연 일정 위험.

## 6. 외주 업체 후보 (3곳, 견적 비교)

### A. 케빈스룸 (1순위 추천)
- **이유**: 1개부터 제작, 캐릭터 봉제 전문, 샘플 25만원~ (절개부 추가 가공 시 +α)
- **연락**: 1599-1206 또는 070-4333-2019
- **홈페이지**: https://www.kevinsroom.co.kr/plushdoll
- **장점**: 견적 빠름, 도면 기반 제작 가능
- **단점**: 절개부 가공이 일반 인형보다 추가 비용 발생 가능

### B. 아이디어스 핸드메이드 작가 (2순위)
- **이유**: 개인 작가 직접 의뢰, 5~15만원 범위 가능
- **검색**: https://www.idus.com/search?word=%EC%A3%BC%EB%AC%B8%EC%A0%9C%EC%9E%91%EC%9D%B8%ED%98%95
- **장점**: 가장 저렴, 1:1 협의 자유
- **단점**: 절개부 가공 경험 작가 찾기 어려움. 견적 편차 큼

### C. 크몽 봉제 프리랜서 (3순위)
- **이유**: 검색 폭 넓고 가격 비교 쉬움
- **카테고리**: https://kmong.com/ (봉제/인형 검색)
- **장점**: 다양한 견적
- **단점**: 1인 작가라 일정 변동 위험

→ **추천 순서**: A 먼저 견적 → 2~3일 응답 없으면 B/C 병행 견적 → 최저가 + 일정 맞는 곳 선정.

## 9. 견적 후 결정 기준

1. **납기 우선** — 4주 안에 도착 가능한 곳 우선
2. **절개부 가공 능력** — 디스플레이 절개(16×9cm) 깔끔하게 마감 가능한지 (가장 위험한 부분)
3. **세금계산서 발행** — 학교 회계 처리 가능 여부
4. **가격** — 위 3개 동등하면 최저가
