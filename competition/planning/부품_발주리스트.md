## 판단 요약

- 이전안은 **외부 27W USB-C 어댑터 연결형**이라 들고 돌아다니는 시연에는 부족했다.
- 이동형 시연을 위해 **Raspberry Pi 5용 5.1V/5A UPS HAT + 18650 배터리 2개**를 예산에 추가한다.
- Pi 5는 전원 요구가 까다롭다. 일반 보조배터리도 켜질 수는 있지만 5V/5A가 안정적으로 안 나오면 저전압/USB 전류 제한이 생길 수 있어, 인형 내부에는 Pi 5용 UPS HAT를 우선한다.
- Remini 인형은 로컬 LLM 장비가 아니라 **H200 서버에 접속하는 환자용 클라이언트**다. 따라서 SSD보다 화면, 마이크, 스피커, 카메라, 전원/배터리 안정성이 중요하다.
- 예산 확보를 위해 외장 SSD, micro HDMI 케이블, USB 허브, LED 장식, 데스크탑형 FIFINE K669는 제외한다.
- Camera Module 3는 품절/납기 지연 신호가 있어 **35,000원 이하 UVC USB 웹캠 대체**까지 열어둔다.

## 발주 전 체크리스트

- [ ] UPS HAT는 반드시 **Raspberry Pi 5용 5.1V/5A 출력** 모델로 산다.
- [ ] 18650 배터리는 같은 제조사/같은 용량/같은 보호회로 제품 2개를 세트로 산다.
- [ ] 배터리와 UPS HAT는 인형 솜에 직접 닿지 않게 절연/난연 보호층을 둔다.
- [ ] 봉제 업체에 150,000원 기준 견적 요청. 180,000원 이상이면 부자재 항목을 줄이거나 절개부 사양을 단순화한다.
- [ ] Display 2는 DSI 연결이므로 micro HDMI 케이블을 사지 않는다.
- [ ] Camera Module 3 재고가 없으면 35,000원 이하 UVC USB 웹캠으로 대체한다.
- [ ] Pi Camera Module 3를 쓰는 경우 Raspberry Pi OS에서 Chromium `getUserMedia`가 카메라를 잡는지 즉시 테스트한다.
- [ ] 소형 USB 핀마이크는 매립 전 STT 테스트를 먼저 한다. 인식률이 낮으면 시연용 외장 마이크를 책상 아래에 보조 배치한다.
- [ ] 배터리 구동 시간은 실제 부하로 테스트한다. 7인치 LCD와 카메라를 켜면 시연 기준 약 40~70분 수준으로 잡고, 장시간 시연은 27W 어댑터를 병행한다.

## 시스템 적합성 메모

- **유지**: Pi 5, 7인치 터치 LCD, 카메라, 마이크, 스피커, 공식 전원, 백업 microSD.
- **추가**: Pi 5 UPS HAT, 보호회로 18650 배터리 2개.
- **제외**: 외장 SSD, micro HDMI 케이블, USB 허브, LED 장식, 데스크탑형 FIFINE K669.
- **리스크**: UPS HAT 국내 재고, 18650 안전 관리, Camera Module 3 품절, Pi 5 준비기간, 매립형 마이크의 STT 품질.
- **대응**: UPS HAT는 동급 대체품 허용, 카메라는 UVC 웹캠 대체 가능, 마이크는 외장 마이크 백업, 장시간 시연은 27W 어댑터 병행.
