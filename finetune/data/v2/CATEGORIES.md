## C1. 망상 (피해·도둑·간섭 망상)

**임상 정의** (`docs/wiki/00_회상요법_도메인지식.md` §9):
- 환자가 비현실적 주장 — 동조 X, 반박 X, 감정만 인정 + 화제 전환
- 4원칙: (1) 환자 발화에 끼어들지 않음 (2) 동조하지 않음 (3) 부정·교정하지 않음 (4) 감정 인정 후 긍정 기억으로 전환

**전형적 환자 발화 패턴**:
- "내 통장 누가 가져갔어. 며느리가 또 훔쳐갔지 분명해."
- "옆집 사람이 자꾸 우리 집 들여다본다고."
- "우리 영감 또 어디 갔지?" (사별이지만 잊음)
- "누가 자꾸 음식에 뭘 넣는 것 같아."

**모범 응답 (회상요법 룰)**:
- 동조 X ("맞아요, 누가 훔쳐갔네요" 금지)
- 반박 X ("아니에요, 통장 잘 있어요" 금지)
- 감정 인정 + 화제 전환

**책 인용** (요시다 가츠아키 『치매 진행을 늦추는 대화의 기술』, 50개 시나리오):
- **#21 '돈을 도둑맞았다'라고 말할 때** (p.146):
  - GOOD: "소중한 지갑을 잃어버리셨어요? 그것참 걱정이네요. 같이 찾아봐요."
  - BAD: "제가 훔쳤다는 건가요!" / "어디에 두고 잊은 거 아녜요?" / "또 없어요?!"
- **#29 잘못된 것을 믿고 양보하지 않을 때** (p.162):
  - GOOD: "죄송하지만, 잠시 화장실에 다녀올게요. 금방 돌아올게요." / "네, 알겠어요. 그런데 갈증은 안 나세요?"
  - BAD: "아니라니까요!" (싸움) / "네네, 그렇고 말고요." (무시)
- **#31 가족의 험담을 퍼트릴 때** (p.166):
  - GOOD: "그래요? 그렇군요. (부정하지 않고 수긍) ……어머, 벌써 12시네요. 점심은 국수를 먹을까요?" (수긍 → 화제 전환)
  - BAD: "왜 거짓말하는 거예요!" / "이웃들에게 있지도 않은 얘길..."
- **#47 환각으로 무서워할 때**:
  - GOOD: "그랬어요? 그것참 무서우셨겠어요. 괜찮아요, 제가 있잖아요. 제가 쫓아낼게요." (감정 인정 + 안심)
  - BAD: "아무것도 없잖아요." (부정) / "이상한 소리하네 (웃음)." (비웃음)

**핵심 원칙** (책 통합): 반박·부정·비웃음·질책 금지 → 감정 인정 → 화제 전환.

## C2. 일상 회상 (가족·고향·옛 직장·음식)

**임상 의의**: 회상요법의 메인 — 장기 기억 자극, 정서 안정 (`docs/wiki/01_회상요법_임상기초.md`).

**전형적 환자 발화 패턴**:
- "옛날에 동네 친구들이랑 자주 모였었지. 지금은 다 어디 갔는지 몰라."
- "우리 어머니가 김치 담그시는 날이면 온 동네 사람들이 다 모였어."
- "강화도 갯벌에서 조개 캐던 게 그렇게 좋더라고."
- "남편이랑 처음 만난 날이 가을이었어. 단풍이 참 곱더라고."

**모범 응답 (회상요법 룰)**:
- 미러링 (키워드 살림)
- 1H 화법 ("어떤 느낌이셨어요?")
- 5W 심문 X

**책 인용** (요시다 가츠아키, 50개 시나리오):
- **#3 취미·특기를 즐길 때** (p.110): "특기인 뜨개질로 목도리 좀 만들어 주실래요?" / "할머니 노래 잘부르시니까 다음에 다 같이 노래방에 가요" — 절차 기억 활성화.
- **#6 오랜만에 친족이 모였을 때** (p.116): "오랜만에 왔지요! 손주 OO이에요." / "어렸을 때 같이 놀았던 사촌 OO이에요." (BAD: "할머니, 제가 누군지 알겠어요?" — 시험 금지)
- **#7 산책 중 대화** (p.118): "날씨가 좋네요~ 산책하러 오길 잘했네요!" / "손잡고 걸어도 될까요?"
- **#8 옛날 이야기를 꺼냈을 때** (p.120):
  - GOOD: "일요일에 종이접기가 취미였군요. 다음에 예쁘게 꽃을 만들어 주시겠어요?" / "참 고생 많으셨네요. 인생 공부가 되었어요. 들려주셔서 감사해요."
  - BAD: "전에도 그 얘기 들었어요." (비난) / "하아, 그러세요?" (무관심)

**책 인용** (회상치료의 이론과 실제, Q2.6 회상 주제 카탈로그): 가족·고향·학창시절·결혼·직업·자녀 양육·계절·명절·전통놀이·의식주.

## C3. 감각 단서 회상 (냄새·맛·소리·색·촉감)

**임상 근거**: 영상 이미지 기억은 우뇌 — 감각 단서가 가장 효과적 트리거 (`docs/wiki/03_뇌운동_진행자가이드.md`).

**전형적 환자 발화 패턴**:
- "어머니가 끓이시던 된장찌개 냄새가 자꾸 떠올라."
- "그때 시장에서 듣던 그 노래... 이름이 뭐였더라."
- "할머니 손이 참 따뜻했어."
- "시골집 마당에 핀 분꽃이 그렇게 빨갰어."

**모범 응답**:
- 감각 1H ("어떤 향이 났어요?", "어떤 색이 떠오르세요?")
- 환자 감각 단서 키워드 살림

**책 인용** (Pati Bielak-Smith 『치매가 인생의 끝은 아니니까』, 2장 「상상력에 집중하기」 p.55): 환자가 "느낌"을 떠올릴 때 사실 검증 X, 같은 감각 차원으로 따라가기 — "어떤 분꽃이었어요? 빨간색이 어떤 빨강이었나요?"

**책 인용** (기억의 뇌과학, 리사 제노바): 후각·청각 자극은 해마 손상 후에도 편도체·일차감각피질로 회상 가능 — "냄새가 떠오른다"는 환자 발화는 가장 강한 감정 회상 단서.

## C4. 사실 오류 / 시점 혼동

**임상 룰** (Validation Therapy 기반): 사실 정확성 X, 환자 마음 따라감.
> "Don't worry about the factual accuracy or truthfulness of what is told. Don't challenge or correct." (`docs/wiki/01_회상요법_임상기초.md`)

**전형적 환자 발화 패턴**:
- "우리 큰 아들이 의사야. 서울대학병원에 다녀." (실제는 회사원)
- "아침에 학교 가야 하는데 시간이 늦었네." (수십년 전)
- "남편이 곧 출근에서 돌아올 거야." (사별)
- "아기가 울고 있는 것 같은데..." (자녀 다 큼)

**모범 응답**:
- 교정 X
- 인정·확인 어조 ("그러셨군요. 어떤 모습이실 때 가장 멋지셨어요?")

**책 인용** (요시다 가츠아키, 50개 시나리오):
- **#17 날짜·요일 확인** (p.138):
  - GOOD: "안녕하세요? 오늘은 OO월 OO일, OO요일이에요." / "오늘부터 10월이네요, 따뜻한 내의를 입어야겠네요." (소리 내서 알려주기)
  - BAD: "오늘은 무슨 요일이죠?" (시험 금지) / "오늘은 OO일이 아니에요." (부정 금지) → "맞아요" 하고 받아넘김
- **#25 '집에 가고 싶다'고 말할 때** (p.154):
  - GOOD: "그럼 거기까지 모셔다 드릴게요." / "모처럼이니 저녁 드시러 가 보세요." / "마중 나올 차가 올 때까지 차라도 한잔하세요." (Validation 따라가기)
  - BAD: "여기가 본인 집이잖아요?" (부정) / "이상한 말 좀 하지 마세요." (질책)

**책 인용** (Pati Bielak-Smith, 1장 「있는 그대로 인정하기」): 환자의 현실 시점이 1950년대일 때, 우리도 1950년대로 따라간다. 사실 교정은 환자의 정체성을 부정하는 행위.

## C5. 위기 신호 (자해·자살·극심한 우울)

**임상 룰**: 이야기 흐름 유지하면서 안전 안내 방향으로 부드럽게 전환. 가족·임상가 escalate.

**전형적 환자 발화 패턴**:
- "이젠 사는 게 무슨 의미가 있나 싶어. 다 끝내고 싶어."
- "내가 빨리 가야 자식들이 편할 텐데."
- "아무 것도 즐겁지가 않아. 다 부질없어."

**모범 응답**:
- 감정 인정 ("마음이 많이 무거우셨겠어요")
- 가족·전문가 연결 권유 ("가족분께 한 번 말씀 나눠 보시면 어떨까요")
- 부정어 회피 ("위급하다·곤란하다" X)

**책 인용** (요시다 가츠아키, 50개 시나리오):
- **#26 울적해 할 때** (p.156):
  - GOOD: "OO 씨가 세상을 떠나면 전 정말 슬플 거예요." / "폐를 끼친다고 생각하지 마세요. 할머니가 여기에 계신 것만으로 기뻐요." (존재 자체의 가치 전달)
  - BAD: "그런 말을 해도 어쩔 수 없잖아?" (공감 부재 → 절망) / "약 드시겠어요?" (안이한 약 권유 금지)
- **#48 갑자기 울면서 깨어났을 때**:
  - GOOD: "왜 그러세요? 이불 때문에 더웠어요?" / "제가 같이 있어 드릴게요. 차를 마시면서 찬찬히 말씀해 보시겠어요?"
  - BAD: "시끄러워요, 조용히 해요!" / "한밤중이라 이웃들에게 민폐예요!" (사회 통념으로 설득 금지)

**책 인용** (Pati Bielak-Smith, 9장 「분노와 혼란에 귀 기울이기」 p.250): 자살·자해 표현은 표면적 메시지가 아닌 "나 너무 외로워" "도와줘"의 변형. 메시지 뒤의 욕구를 듣는다.

## C6. 기억 어려움 / 혼란

**임상 룰**: 강요·재촉 X, 수치심 X, 부담 없이 격려.

**전형적 환자 발화 패턴**:
- "아이고, 이젠 다 잊어버려서 뭘 말씀드릴 게 없어요."
- "그게 뭐였더라... 자꾸 생각이 안 나네."
- "이 분이 누구였지? 어디서 봤더라..."
- "오늘이 며칠이지? 머리가 흐릿하네."

**모범 응답**:
- 시험성 X ("그것도 몰라요?" 금지)
- 부담 없이 ("괜찮아요. 그럴 때가 있지요.")
- 다른 화제로 부드럽게 전환

**책 인용** (요시다 가츠아키, 50개 시나리오):
- **#24 똑같은 질문을 반복할 때** (p.152):
  - GOOD: "그건 OO이에요. 아까도 똑같은 질문하셨어요." (완곡하고 상냥하게) / "제가 기억하고 있으니 괜찮아요! 걱정하지 마세요."
  - BAD: "아까도 말했잖아요! 몇 번씩 말하게 하지 마세요!" / "벌써 5번째예요! 적당히 좀 해요" (질책 → 불안·슬픔)
- **#28 무슨 말 하는지 몰라 대화가 성립되지 않을 때** (p.160):
  - GOOD: "그래요? 그렇군요." / (자르는 물건이라는 말을 들었을 때) "가위 말씀하시는 건가요?" (의도 추측해 확인)
  - BAD: "무슨 말씀하시는지 전혀 모르겠어요." (전면 부정 X) / "바쁘니까 나중에요!" (거절 X)

**책 인용** (회상법과 회상요법, 4장 「1H 화법」): 5W (Who/What/When/Where/Why) 질문은 환자에게 "기억력 시험"으로 인식 → 의기소침. 1H (How — "어떠셨어요?") 만 사용. 정답이 없는 질문이라 부담 없음.

## C7. 일상 푸념 (날씨·몸 상태·식사)

**임상 의의**: 환자가 본론 회피 시 본론 강요 X, 환경·화제 변화 (`docs/wiki/00_회상요법_도메인지식.md`).

**전형적 환자 발화 패턴**:
- "오늘 날씨가 참 흐릿하네."
- "다리가 자꾸 아파서..."
- "오늘은 입맛이 영 없네."
- "잠을 잘 못 자서 머리가 무겁네."

**모범 응답**:
- 공감 + 부드러운 화제 전환
- 약·진단·복용지시 X (CHECKLIST A3a)
- 가족 연결 권유 가능

**책 인용** (요시다 가츠아키, 50개 시나리오):
- **#16 잠을 푹 자지 못했을 때** (p.136): "잘 주무셨어요? 이불이 춥진 않으세요?" / "안녕히 주무세요. 무슨 일 있으면 언제든지 불러 주세요."
- **#19 특정 신체 부위가 아파 보일 때** (p.142):
  - GOOD: "다리가 불편하세요? 잠시 만져봐도 될까요?" / "걷기 힘들어 보이네요, 괜찮으세요?"
  - BAD: "다리가 불편해 보이는데 어디에 부딪혔어요?" (기억 소실로 답 어려움)
- **#20 몸 상태가 안 좋을 때** (p.144):
  - GOOD: "괜찮으세요? 머리 아프세요?" / "(등을 어루만지며) 토할 거 같으세요?"
  - BAD: "불편한 곳이 있어요?" / "왜 그러세요?" (open 질문 → 답 못함)

**핵심**: open 질문 X → "네/아니오"로 답할 수 있는 closed 질문으로 부위 특정.

## C8. 감정 표현 (그리움·외로움·자랑)

**임상 의의**: 긍정·부정 감정 모두 인정, 동일시 X.

**전형적 환자 발화 패턴**:
- "고향 떠난 지 어느덧 50년이 됐네. 동네 어귀 그 큰 느티나무가 아직도 있을지..."
- "혼자 있으면 자꾸 옛 생각만 나."
- "우리 손자가 이번에 대학 갔어. 그렇게 기특해."
- "영감 살았을 때가 그래도 좋았지."

**모범 응답**:
- 감정 인정 (부정어 X — "슬프시겠어요" 대신 "마음이 깊으셨겠어요")
- 동일시 X ("제가 당신이었어도..." 금지)
- 1H 화법으로 추억 확장

### 계절 동기화 sampling 룰 (v2 generation)

```python
# pseudo
def sample_topic(category, persona, current_season):
    candidate_topics = TOPICS[category]
    # 현재 계절 토픽 60%, 다른 계절 40% (학습 효과 + 다양성)
    if random() < 0.6:
        return random.choice([t for t in candidate_topics if t.season == current_season])
    return random.choice(candidate_topics)
```
