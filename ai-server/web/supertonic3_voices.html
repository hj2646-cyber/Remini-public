🎤 Supertonic 3 — Voice 비교 (한국어)

10개 voice (여 5 + 남 5) 동일 텍스트 합성. 마음에 드는 voice 의 "이 voice 선택" 클릭 → 하단에 적용 방법 표시. 환자 UI 우측상단 picker 에서 즉시 변경도 가능 (재시작 X).
short: "안녕하세요. 오늘 기분이 어떠세요?" medium: "오늘 점심에 뭐 드셨어요? 옛날에 어머니가 해주시던 김치찌개가 갑자기 생각나네요."
